# 歌词字幕特效：纸条 / 大字 / 动态排版

来自《把回忆拼好给你 · 线稿版》（2026-10）。原来的细手写字固定在画面底部，用户嫌"有点看不清"，要"动效比较强"。于是做了三种样式出对比小样，用户的评价是"这三个格式都超级好"。

一个文件 `lyricfx.js`，和画风无关：画在一张 2D canvas 上，每帧只看时间 t，可以跳着渲染、分段渲染。水彩和漫画两套引擎都已经接好；SVG 线稿那种页面，就在画面上面盖一张透明 canvas（做法见最后一节）。

| 样式 | 样子 | 适合 |
|---|---|---|
| `slip` 纸条贴字 | 每句写在一张手撕白纸条上，"啪"地拍进画面，两头贴胶带。整句先用浅灰显示，唱到的字变黑、跳一下。下一句拍上来时，旧纸条被撕走 | 最好认，什么背景都清楚；手作、拼贴、纸张题材 |
| `pop` 大字蹦出 | 不垫底，粗白描边加投影。唱到哪个字，那个字就从小弹出来，正在唱的字放大。整句停到下一句开始前，退场时逐字掉下去 | 最像字幕，动感中等；画面本身很满时用 |
| `kinetic` 动态排版 | 每句拆成几块，一块块砸进画面的空白处，画面跟着抖；关键词黑底白字、特别大；退场时往两边甩出去 | 最炸；副歌、爆发段。代价是每句要按镜头手摆位置 |

可以混搭，比如主歌用纸条、副歌用动态排版：`style: i => i >= 10 ? 'kinetic' : 'slip'`。

三种都不用彩色。用户的片子里红色一般留给主角的标志物和拟声字，所以字幕点亮靠变黑、变大、跳动来表现。

## 先看效果（在资源库根目录）

```bash
node render.mjs --page=lyricfx/demo.html --sheet=1.5,4.5,7.5,10,12.8,15.5 --cols=3 --out=out/check/lyricfx.jpg   # 缩略图
node render.mjs --page=lyricfx/demo.html --clip --out=out/lyricfx_demo.mp4                                          # 18 秒示例片
```

浏览器里直接打开 `lyricfx/demo.html` 会循环播放。加 `?ly=kinetic` 全程只看一种样式，加 `?t=12.8` 停在某一秒。

## 在水彩 / 漫画项目里用

歌词 `LY` 照常写在 `music.js` 里（格式见手册第 2 节，有逐字时间最好）。在 `LY` 旁边加一行，就从默认的字幕换成这三种之一：

```js
const LYRIC_FX = { style: 'slip' };                                   // 或 'pop' / 'kinetic' / (i, line) => 样式
```

不写 `LYRIC_FX` 就还是原来的字幕：水彩版是墨块加黄字，漫画版是旁白框。想临时比较，就在浏览器的网址后面加 `?ly=slip`、`?ly=pop` 或 `?ly=kinetic`。

开新项目时，除了手册第 7 节和 `manga/README.md` 里的拷贝命令，还要多拷这些：

```bash
cp -r $B/lyricfx $P/
cp $B/fonts/{MaShanZheng,ZCOOLKuaiLe}-Regular.ttf $P/fonts/                 # 水彩版拷 fonts/ 时已经带上
sed -i 's#\.\./lyricfx/#lyricfx/#; s#\.\./fonts/#fonts/#' $P/studio.html    # 只有漫画版要：studio.html 从 manga/ 挪到了根目录
```

两个字体都是完整的 TTF，云端机器没有中文字体也能显示。用之前先查一遍歌词里的每个字，两个字体里都有（第 4 节有命令）。

## 动态排版要手摆

`kinetic` 不摆也能跑：自动拆成两三块，按句号轮流放在四个角。但想好看，要按每个镜头的空白处一句句摆：

1. 截出每句**开头、中间、结尾**三帧**不带字幕**的画面，看清哪里空：临时把 `LYRIC_FX` 写成 `{ style: 'none' }`，或者在浏览器网址后面加 `?ly=none`，字幕就不画了。副歌一句常常跨两个镜头，摆的位置要在两个镜头里都空着。
2. 每句写一条 `layout`：

```js
const LYRIC_FX = {
  style: 'kinetic',
  layout: {
    // 句号: chunks 用 / 分块、【】标关键词（去掉符号必须和歌词一字不差，不然控制台报警告）
    1: { chunks: '我知道你/爱集邮/爱笑/甚至爱/【发呆】', pos: [[560, 1005, -2, .8], [430, 250], [972, 250], [1330, 215, 3, .8], [1560, 990, -4, .75]] },
    8: { chunks: '在为我/【焦虑】/失神慌张/之中醒来', at: [1640, 420], s: .8 },
    11: { chunks: '全部都/小心地/【收集】', at: [400, 330], tb: [78, 80, 82] },
  },
};
```

- `at: [x, y]`：几块竖着叠在这个点周围，左右错开一点。`s` 是整句缩放，`r` 是整体角度，`stagger` 控制左右错开多少。
- `pos: [[x, y, 角度, 缩放], ...]`：每块各放各的位置，适合"分格里各放一块"这种。角度和缩放可以省略。
- `tb: [第几拍, ...]`：每块砸在第几拍，拍号从 0 数，和分镜一样。不给就跟着这块第一个字唱出来的时间。**副歌（尤其是没有逐字时间的句子）用 `tb` 把关键词砸在鼓点、爆发点上，效果最好。**
3. 出缩略图检查：字不要压在人脸、拟声字和"说明画面意思"的小东西上（比如人物发呆时冒出的小云朵）。压到了就挪位置，或者缩小一点。

没有逐字时间的句子，三种样式都会把字排在半拍网格上（一个字半拍，唱不下就压缩），看起来是踩着拍子出来的。

## 选项（`lyricFX(ctx, t, 选项)`）

| 选项 | 说明 |
|---|---|
| `lines` | 歌词 `[[开始, 结束, '歌词', [[字开始, 字结束], ...]?], ...]` |
| `style` | `'slip'` / `'pop'` / `'kinetic'`，或 `(i, line) => 样式` |
| `beats` | 每拍的时间（升序）；两套引擎会自动按 `PROJECT.bpm / offset` 生成 |
| `layout` | 动态排版的摆位，见上一节 |
| `fonts` / `size` / `y` | 各样式的字体、字号、中心高度。默认纸条用马善政 86 号，大字和动态排版用站酷快乐体 100 / 116 号；纸条和大字在离底边 1/10 的位置 |
| `ink` / `paper` / `dim` | 墨色、纸色、纸条上还没唱到的字的颜色 |
| `lastUntil` | 最后一句停到第几秒（默认唱完再停 1.2 秒；片尾有片名时可以停到结尾的最后一下） |
| `boil` | 线条抖动的节拍 `t => 整数`，默认每秒 10 次；引擎里跟着 `BOIL` 走 |

返回 `{ shake: [dx, dy] }`，动态排版砸字时画面要抖多少。`ctx` 传 `null` 就只计算抖动、不画字。两套引擎在画画面之前先这样算一次，再把画面挪一下并放大一点点，这样边缘不会露白（`POST.shake`）。

## 坑

- **细的手写体做字幕看不清**：龙藏体这类细笔画的字，和线稿的线条一个颜色、一样粗，混在画里分不出来，而且偏草（"无"像"元"）。字幕要么有底（纸条），要么粗描边加投影（大字、动态排版）。
- **字体的简繁坑**：龙藏体把简体"时"画成繁体"時"。换字体之前把歌词用到的字都查一遍：先看 cmap 里有没有（`fontTools` 的 `getBestCmap()`）；有也可能画成别的样子，要出一张大图逐字看。
- **字一个个"写出来"会读不完**：大部分时间屏幕上只有半句。整句先显示（纸条），或者唱完整句一直停到下一句开始前（三种都是这样）。
- 句子之间的间隔常常只有 0.03～0.5 秒。纸条是新的盖在旧的上面，再把旧的撕走；大字在下一句开始前 0.28 秒内退场；动态排版是新块砸进来时旧块往外甩，同一时刻两句可以同时在画面里。

## 别的页面怎么接（比如 SVG 线稿）

`《把回忆拼好给你》线稿版`（`~/project/testt/videos/pinhui-lineart-mv`）是 SVG 引擎，接法是：

- `main.js` 在 SVG 上面盖一张透明 canvas，按 `devicePixelRatio` 放大，和画面对齐。
- `karaoke.js` 每帧先清空这张 canvas，再调用 `lyricFX`，把返回的 `shake` 写到画面那一层的 `transform` 上。
- 网址加 `?ly=` 可以切换样式。

截图和录屏会把 canvas 一起拍进去，不用改渲染脚本。
